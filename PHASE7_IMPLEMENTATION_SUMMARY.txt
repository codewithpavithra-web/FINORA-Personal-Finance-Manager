================================================================================
EXPORT/IMPORT FUNCTIONALITY DETAILS
================================================================================

JSON BACKUP FORMAT:
{
  "version": "1.0",
  "exportDate": "ISO string",
  "transactions": [...],
  "budgets": [...],
  "savingsGoals": [...],
  "profile": {...}
}

CSV EXPORT FORMAT:
Date,Type,Title,Category,Amount,Payment Method,Notes
2024-08-30,expense,Groceries,Food,500,"Debit Card","Weekly shopping"
...

FILE NAMING:
- JSON: finora-backup-YYYY-MM-DD.json
- CSV: finora-transactions-YYYY-MM-DD.csv

IMPORT PROCESS:
1. User selects .json file
2. File is parsed and validated
3. Confirmation modal shows data summary
4. Shows warnings about data replacement
5. User confirms import
6. Data is imported via importData() method
7. Page refreshes to load new data
8. Success notification shown
