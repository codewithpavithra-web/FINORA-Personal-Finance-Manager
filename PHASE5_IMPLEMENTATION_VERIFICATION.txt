DATA STRUCTURE
================================================================================

GOAL OBJECT:
{
  id: timestamp (Date.now()),
  title: string (goal name),
  targetAmount: number (₹),
  saved: number (₹),
  dueDate: ISO string or null (optional),
  icon: emoji string,
  createdAt: ISO string
}

EXAMPLE:
{
  id: 1693310400000,
  title: "New Laptop",
  targetAmount: 80000,
  saved: 42000,
  dueDate: "2024-10-20T00:00:00.000Z",
  icon: "💻",
  createdAt: "2024-04-20T12:30:45.000Z"
}

LOCALSTORAGE KEY:
finora_savings_goals (JSON array of goal objects)

PERSISTENCE:
- Automatically saved via useEffect in FinanceContext
- Loaded on app init from localStorage
- Falls back to getInitialSavingsGoals() if empty
- Separate storage from transactions and budgets
- No key conflicts
